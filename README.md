# Deep-Learning-Project
Deep Learning case study on Mark Sheet OCR using Python, PaddleOCR, and OpenCV to extract and organize academic information from mark sheet images. Developed by Bhargav, Vishal, Pranav, and Bheeshma under the guidance of Panigrahi Srikanth, Assistant Professor, Department of CSE (AI &amp; ML), CBIT, Hyderabad.
